このページは、bmdのNormal / Search / Preview各モードのキー操作を扱います。上書きは [設定](/projects/bmd/configuration/) の `[keymap.*]` で行います。最短の起動は [使い方](/projects/bmd/usage/) へ。

## Normalモード

| キー | 動作 |
|---|---|
| `j` / `↓` | 2行下へスクロール |
| `k` / `↑` | 2行上へスクロール |
| `d` / `PageDown` | 半ページ下 |
| `u` / `PageUp` | 半ページ上 |
| `g` / `G` | 先頭 / 末尾 |
| `[` / `]` | 前 / 次の見出し |
| `t` | 見出しアウトラインの開閉（選択はスクロール位置に追従。エントリのクリックでジャンプ） |
| `ma` / `'a` | スクロールマークを置く / 飛ぶ（`a`–`z`） |
| `Tab` / `n` | 文書内の次のリンクへスクロール（検索中は次ヒット） |
| `Shift-Tab` / `N` | 文書内の前のリンクへスクロール（検索中は前ヒット） |
| `o` / `Enter` | 選択リンクを開く / プレビュー（`#anchor`は文書内ジャンプ） |
| `O` / `Esc` | 1段戻る（プレビューを閉じる、または直前のジャンプ・ファイルへ） |
| `/` / `?` | 前方 / 後方検索開始 |
| `h` | ヘルプ表示（`Esc` で閉じる） |
| マウスホイール | スクロール |
| `q` / `Ctrl-c` | 終了（`Esc`は検索中なら検索クリア、それ以外は `O` と同じく1段戻る） |
| リンクを左クリック | 開く / プレビュー |
| 脚注マーカーを左クリック | 脚注プレビューを開く |
| チェックボックスを左クリック | セッション内でトグル（保存しない） |
| アウトラインを左クリック | 見出しへジャンプ |
| ドラッグ | テキスト選択（ハイライトのみ。コピーは `y`） |
| `y` | 選択をコピー。選択が無ければ `l` リンクURL、`h` 見出し `#slug`、`c` 最寄りコードブロック |

リンク巡回は文書全体を順に辿り、末尾から先頭へ折り返します。脚注マーカーは巡回に含みません。ヘルプは現在のkeymapで割り当てたキーを一覧し、短い端末ではスクロールします。`close_help` と `toggle_checklist` は既定で未割り当てです。

## 検索入力モード

| キー | 動作 |
|---|---|
| 文字 | クエリに追加（入力中もヒットを強調し、件数を表示） |
| `Backspace` | 1文字削除 |
| `Enter` | 確定し、最寄りのヒットへ移動してNormalへ |
| `Esc` | 入力キャンセル |

## Previewモード

| キー | 動作 |
|---|---|
| `Esc` / `o` / `O` | プレビューを閉じる |
| `+` / `=` / `-` | ズームイン / アウト |
| `0` | フィットにリセット |
| Ctrl+トラックパッドピンチ | ズーム |
| プレビュー外を左クリック | 閉じる |
| `q` / `Ctrl-c` | 終了 |

## リンクの種類

| 種類 | 例 | `o` / `Enter` |
|---|---|---|
| Web | `[text](https://…)` | OSのブラウザで開く |
| Anchor | `[text](#section)` | 見出しへジャンプ |
| Document | `[text](./other.md)` | 同ビューで開く（`#section` 付きならその見出しへ） |
| Image | `![alt](path.png)` | フローティングプレビュー |
| Mermaid | mermaidコードブロック | 描画プレビュー |

各スタックは最大64層です。描画方式の詳細は [レンダリング](/projects/bmd/rendering/) を参照してください。
